Matchday: как выложить и установить

1. GitHub Pages: создайте репозиторий и загрузите в него всё содержимое этой папки
   (index.html, manifest.webmanifest, sw.js и папку icons). В Settings > Pages выберите
   ветку main и корень. Через минуту появится ссылка вида
   https://ваш-ник.github.io/имя-репозитория/
2. Откройте ссылку в Chrome на телефоне: меню (три точки) > "Установить приложение".
3. Для APK: сайт pwabuilder.com, вставьте ссылку, нажмите Package for stores > Android.

Данные хранятся в браузере отдельно для каждого адреса. Перед переходом на новый адрес
скопируйте "Резервную копию" во вкладке "Ещё" и вставьте в "Восстановление".
